# sacc-step-select
Analyzing and modelling gaze fixation data using the step selection method

## Installation
Dependencies are listed in `requirements.txt`.

Mixed-effect modelling uses `pymer4`, which requires a separate R
installation. The R packages `lme4`, `lmerTest`, and `emmeans` are
also required. R must be available to the Python process before
opening the notebook.

## Code for *Self-crossing avoidance as a visual search strategy*:
The Jupyter notebook `Paper1.ipynb` generates all figures and results in the paper. 

Open it from the repository root and select the Python environment
containing the installed dependencies as its notebook kernel.

Run the cells in order.
